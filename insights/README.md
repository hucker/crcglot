# Usage insights

Claude Code usage reports generated by the `/insights` slash command, **scoped to crcglot sessions only**.  One HTML file per run, named `report-YYYY-MM-DD-HHMMSS.html` by the generator.

## Scope: crcglot only

A default `/insights` run samples recent sessions across every repo worked on in the window, so a raw report usually describes other projects and says nothing about crcglot.  Those do not belong here.  Before filing a report, check that every session it covers came from this repo.  The session metadata behind a run records the originating repo per session:

```powershell
Get-ChildItem "$env:USERPROFILE\.claude\usage-data\session-meta\*.json" |
  ForEach-Object { (Get-Content $_ -Raw | ConvertFrom-Json).project_path }
```

Every path listed must be this repo.  If any is not, the report is cross-project: do not file it, and re-run `/insights` asking for crcglot sessions only.

crcglot's own transcripts live in `~/.claude/projects/c--Users-chuck-src-repo-crcglot/`.  They are pruned after `cleanupPeriodDays` (30 by default), which caps how far back any report can reach.

## Filing a new report

`/insights` writes its output to `~/.claude/usage-data/`.  Copy the timestamped file (not `report.html`, which is only a copy of the most recent run) into this directory, add a row to the table below, and commit:

```powershell
Copy-Item "$env:USERPROFILE\.claude\usage-data\report-<stamp>.html" insights\
```

Keep the generated filename, and treat a filed report as immutable.  Each one is a snapshot of a window of sessions, so editing or regenerating it after the fact destroys the record of what those sessions looked like on the day it ran.

This repo is public.  Read a report before filing it and confirm you are content to publish what it describes.
